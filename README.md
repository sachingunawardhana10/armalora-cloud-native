 Armalora

## Cloud-Native Craft & Lifestyle E-Commerce Platform

Armalora is a cloud-native e-commerce platform for craft and lifestyle products.

The project is being developed using Go, PostgreSQL, Docker, GitHub Actions, Terraform, AWS, Kubernetes, Prometheus, Grafana, and DevSecOps practices.

## Main Features

- Customer registration and authentication
- Product catalog
- Categories and product variants
- Inventory management
- Shopping cart
- Wishlist
- Checkout and orders
- Cash on Delivery
- Online payments
- Customer purchase history
- Full admin portal
- Craft Kit Builder
- Customer chatbot
- Monitoring and observability
- Automated CI/CD
- Containerized deployment
- Kubernetes deployment
- Infrastructure as Code
- Security scanning
- Failure recovery and rollback
